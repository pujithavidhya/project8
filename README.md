# PROJECT 8 – STUDENT MARKS MATRIX ANALYSIS

## About the Project
The Student Marks Matrix Analysis project is designed to analyze student marks stored in a matrix (2D list). It processes marks of multiple students across different subjects and calculates useful academic statistics such as total marks, average marks, highest marks, and lowest marks. It helps understand and compare student performance across subjects.

## Technologies Used
- **Python** – Used to develop the marks analysis program.
- **Lists** – Used to store student marks.
- **2D Lists (Matrices)** – Used to organize marks of multiple students across subjects.
- **Loops** – Used to process student marks.
- **Conditional Statements** – Used to identify highest and lowest marks.
- **Arithmetic Operations** – Used to calculate totals and averages.

## Main Features
- Accepts marks of multiple students.
- Stores marks in a 2D list (matrix).
- Calculates total marks for each student.
- Calculates average marks for each student.
- Identifies the highest and lowest marks.
- Analyzes subject-wise performance.
- Displays a student marks analysis report.

## Algorithm
1. Start the program.
2. Get the number of students.
3. Get the number of subjects.
4. Accept marks for each student in every subject.
5. Store the marks in a 2D list.
6. Calculate the total marks of each student.
7. Calculate the average marks of each student.
8. Find the highest and lowest marks.
9. Analyze subject-wise performance.
10. Display the marks analysis report.
11. Stop the program.
